# Things you need to print for this portable utensils stand:
1x Base
1x Top
2x Short Walls
2x Long Walls

# Assemby

After you print all these then you can assemble the model. You take the base and attach the walls alongside the round bar which can be connected with the joints made.
Then you can attach the top and slide it in the circular holes and have it to use. If you want to pack it then just disassemble everything!
